❌ ERROR: "Gagal memuat data" di halaman Kendaraan
═══════════════════════════════════════════════════════════════════════

PENYEBAB:
1. Backend server tidak running
2. MySQL Database tidak running
3. Database belum dibuat / schema tidak applied


✅ SOLUSI LENGKAP (Step by Step)
═══════════════════════════════════════════════════════════════════════

STEP 1: Pastikan MySQL Berjalan
─────────────────────────────────────────────────────────────────────

Windows:
  • Buka: Services (Services.msc)
  • Cari: "MySQL80" atau "MySQL"
  • Status: "Running"
  • Jika belum: Klik kanan → Start

Verify MySQL berjalan:
  mysql -u root -p
  (tekan Enter jika password kosong)
  
Harusnya muncul:
  mysql>

Exit:
  EXIT;


STEP 2: Setup Database
─────────────────────────────────────────────────────────────────────

Jalankan SQL schema file:

  mysql -u root < backend/config/database-schema.sql

Verify database sudah ada:
  mysql -u root
  SHOW DATABASES;
  
Harusnya lihat "db_parkir1"

Verify tables:
  USE db_parkir1;
  SHOW TABLES;
  
Harusnya ada ~6 tables:
  - users
  - jenis_kendaraan
  - area_parkir
  - tarif_parkir
  - kendaraan
  - transaksi_parkir


STEP 3: Start Backend Server
─────────────────────────────────────────────────────────────────────

Buka Terminal BARU, jalankan:

  cd d:\parkir-project_syeril\backend
  npm install
  node index.js

Harusnya muncul:
  ╔═══════════════════════════════════════════════╗
  ║   APLIKASI PARKIR - BACKEND SERVER            ║
  ║   Server berjalan di http://localhost:5000    ║
  ║   Environment: development                    ║
  ╚═══════════════════════════════════════════════╝

Jangan tutup terminal ini!


STEP 4: Start Frontend Server
─────────────────────────────────────────────────────────────────────

Buka Terminal LAIN, jalankan:

  cd d:\parkir-project_syeril\frontend
  npm install
  npm run dev

Harusnya muncul:
  ▲ Next.js 14.x.x
  
  ○ Local:        http://localhost:3000
  ○ Environments: .env.local

Buka browser: http://localhost:3000

🚀 COMMON ERRORS & FIXES
═══════════════════════════════════════════════════════════════════════

ERROR: "Connection refused: 127.0.0.1:3306"
FIX: MySQL tidak running → Start di Services.msc

ERROR: "Unknown database 'db_parkir1'"
FIX: Run: mysql -u root < backend/config/database-schema.sql

ERROR: "ECONNREFUSED 127.0.0.1:5000"
FIX: Backend tidak running → Run: node index.js di terminal backend

ERROR: "404 - /api/kendaraan not found"
FIX: Backend running tapi API route error → Check console backend

ERROR: "Gagal memuat data" di Kendaraan page
FIX: Semua langkah di atas belum selesai
